# Hastan

Личный ИИ-помощник в виде плагина WordPress: задачи, чек-листы и напоминания через Telegram, разбор сообщений через Claude и коннектор (MCP), через который проекты Claude сами ведут список задач.

## Установка

Скачайте `hastan.zip` из последнего релиза и загрузите его в WordPress: Плагины → Добавить новый → Загрузить плагин. Дальше WordPress сам предлагает обновления из релизов этого репозитория.

## Новая версия

Поднимите `Version` и `HASTAN_VERSION` в `hastan.php` и отправьте изменения в `main`. GitHub Actions сам соберёт `hastan.zip` с зависимостями и выпустит релиз `vX.Y.Z`.
